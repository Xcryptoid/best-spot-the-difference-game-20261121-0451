**Harbour Lights** is a spot-the-difference game with three hand-drawn scenes — a sleepy fishing harbour at sunrise, a lantern-lit night market, and a quiet garden at dusk. Each scene hides ten differences between two near-identical pictures shown side by side. Click a difference on either picture to circle it with a gold ring, a chime and a pop; wrong clicks cost 15 points and 3 seconds; a hint (H) spotlights one unfound difference after a cooldown. A countdown timer, a live "differences left" counter, a score with time bonuses, three rounds of rising difficulty, title / round-clear / victory / time-up screens, keyboard shortcuts (H hint, R restart, M mute, Enter to continue) and a WebAudio-synthesised soundtrack round out the hunt. Everything — art, sounds and music — is original, drawn and synthesised in code, with no network requests and no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Or open `game/index.html` directly — the game is plain static files.
